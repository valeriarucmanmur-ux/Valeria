# Что написать Claude Code

Открой терминал в папке `bali-map-app`, запусти `claude` и вставь сообщение ниже целиком.

---

В этой папке лежит готовый проект моего приложения-карты «Бали без толп» (PWA на HTML/JS + Leaflet). Сначала прочитай CLAUDE.md — там структура, формат данных и правила.

Задача: довести приложение до рабочего состояния на моём телефоне.

1. Запусти `npm run photos` — скачай фото старых мест. Если какие-то не скачались, покажи список, не выдумывай замену.
2. Запусти `npm run check` и исправь ошибки в данных, если они есть (кроме предупреждений о фото, которых нет у источника).
3. Запусти `npm start` и проверь приложение по чек-листу из раздела «Как проверять изменения» в CLAUDE.md — на ширине iPhone и на компьютере. Почини всё, что не работает, и коротко напиши, что исправил.
4. Проверь тайлы Esri на 17-м зуме в районе Чангу (−8.65, 115.13) и Убуда (−8.507, 115.262). Если там серые «Map data not yet available», поставь `maxNativeZoom: 16`.
5. Подними `VERSION` в `app/sw.js`, если что-то менял.
6. Помоги опубликовать папку `app` на Netlify (или Vercel, что проще), чтобы была HTTPS-ссылка. Объясни шаги по-русски и ничего не публикуй и не создавай аккаунты без моего подтверждения.
7. В конце напиши, как установить приложение на iPhone и на Android.

Не меняй дизайн, тексты описаний и id мест без моей просьбы.
