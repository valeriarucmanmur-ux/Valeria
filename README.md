# Бали без толп — приложение

Карта 195 мест Бали с фото, ценами, советами, маршрутами на байке от дома и кнопкой «Где я». Работает как приложение на телефоне (PWA) и офлайн для уже открытых мест.

## Как запустить с Claude Code

1. Распакуйте архив, например в `Документы/bali-map-app`.
2. Нужен Node.js 18 или новее (https://nodejs.org → LTS).
3. Откройте терминал в этой папке и запустите `claude`.
4. Вставьте сообщение из файла `PROMPT.md`.

Claude Code скачает фото, проверит данные, запустит приложение и поможет выложить его по HTTPS-ссылке. После этого откройте ссылку на телефоне и добавьте на экран «Домой».

## Без Claude Code

```bash
npm run photos   # скачать фото
npm start        # открыть http://localhost:5173
```

Подробности для разработки — в `CLAUDE.md`.
