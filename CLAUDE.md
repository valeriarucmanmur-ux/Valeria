# Бали без толп — приложение-карта

Приложение-карта Бали для Валерии и её друзей: 252 проверенных места (водопады, пляжи, кафе, спа, культура…) с фото, ценами, советами и маршрутами на байке от дома. Интерфейс на русском, в стиле Google Maps, светлая тема. Основной сценарий — телефон на улице, одной рукой, при ярком солнце.

Это PWA (устанавливается на телефон с сайта «На экран Домой») на чистом HTML/CSS/JS + Leaflet. Сборщика нет: что лежит в `app/`, то и публикуется.

## Команды

```bash
npm run photos   # докачать недостающие фото в app/photos (1600×1067 и превью 400×400), затем: python3 tools/optimize-photos.py
npm run check    # проверка данных (нужен расшифрованный app/data/places.json или BALI_PASSWORD)
npm start        # локальный сервер http://localhost:5173
```

Node 18+. Зависимостей npm нет (`npx serve` скачивается сам).

## Структура

```
app/
  index.html            весь интерфейс: стили, разметка и логика в одном файле
  data/places.enc.json  зашифрованные паролем данные { version, home, costs[], places[] } — публикуется только этот файл
  data/places.json      расшифрованная копия для правки (в .gitignore, НИКОГДА не коммитить)
  data/roads.json       дорожный граф Бали из OpenStreetMap для маршрутов (см. ниже)
  photos/<id>.jpg       большое фото до 1600 px (progressive JPEG q80); photos/<id>_t.jpg — превью 400×400. Лежат в репозитории
  vendor/               Leaflet 1.9.4 и Leaflet.markercluster 1.5.3 (локально, чтобы работало офлайн)
  icons/, manifest.webmanifest, sw.js   установка на телефон и офлайн-кэш
tools/
  fetch-photos.mjs      скачивает фото по tools/photo-sources.json
  check.mjs             валидатор данных
```

## Пароль и шифрование

Всё приложение закрыто паролем (знает владелица). Данные мест, цены и дом лежат только в `app/data/places.enc.json`
(AES-256-GCM, ключ из пароля через PBKDF2-SHA256, 250 тыс. итераций). При входе `index.html` расшифровывает их в браузере;
при галочке «Запомнить» ключ хранится в localStorage этого устройства, кнопка «Выйти и заблокировать» в разделе «Ещё» его стирает.

Правка данных:
```bash
node tools/crypt.mjs decrypt   # спросит пароль → app/data/places.json
# … правка app/data/places.json …
npm run check
node tools/crypt.mjs encrypt   # спросит пароль → app/data/places.enc.json; коммитить только его
```
Пароль не писать ни в код, ни в коммиты, ни в workflow. Фото (`app/photos`) и дороги не шифруются — это публичные места.

## Данные: place

| поле | что это |
|---|---|
| `id` | целое число, уникальное и **неизменное**: по нему хранятся избранное и «был(а)» в localStorage, и ссылки `#p<id>`. Новым местам давать `max(id)+1`, удалённые id не переиспользовать |
| `name`, `desc` | название как в Google Maps; описание 1–2 предложения на живом русском |
| `cat` | одна из 15 категорий, список в `CATS` в index.html и в tools/check.mjs |
| `region` | район одним названием (Чангу, Сесех, Табанан, Убуд…) — строго из списка `districts[]` в данных; `zone` — часть острова этого района |
| `area` | деревня/район, коротко: «Cemagi, Mengwi, Badung» |
| `lat`, `lng` | координаты, 5 знаков после запятой; проверять по Google Maps |
| `gm` | ссылка Google Maps (с `query_place_id`, если есть place_id) |
| `price`, `level` | цена текстом в IDR; уровень 0 бесплатно, 1 ≤50 тыс., 2 ≤250 тыс., 3 ≤1 млн, 4 >1 млн, `null` неизвестно |
| `hours`, `tips[]`, `fact`, `updated`, `sources[]` | часы, советы, интересный факт, год данных о цене, ссылки-источники |
| `rating`, `reviews` | рейтинг Google и число отзывов (или `null`/0) |
| `src`, `srcLabel` | откуда место: `IG` Instagram, `TG` Telegram, `GM` Google Maps, `Web` открытые источники; можно `"TG + IG"` |
| `ig`, `web` | полные URL или пустая строка |
| `img`, `thumb` | `photos/<id>.jpg`, `photos/<id>_t.jpg` или пусто — тогда показывается значок категории |
| `isNew` | метка «новое» |
| `tags` | метки для подборок (см. «Интерфейс») |
| `pq` | оценка главного фото: 2 хорошее, 1 нормальное, 0 заменить |
| `photos` | (необязательно) доп. фото для галереи: `[{u, a}]` — URL и автор/источник |

`districts` — упорядоченный список районов `[{name, zone}]` (зоны: Юг, Табанан, Убуд и Гианьяр, Горы, Восток, Север, Запад, Острова); по нему строятся фильтр, группы в списке и раздел «Районы». Новый район — добавить сюда.

`home` — дом (`name`, `addr`, `plus`, `lat`, `lng`, `gm`): от него считаются «км от дома» и маршруты по умолчанию. Адрес дома нигде, кроме зашифрованных данных, не писать.

### Как добавить место
1. Проверить, что его ещё нет (по названию и по координатам в радиусе ~150 м). Если есть — обновить существующую карточку, не создавать дубль.
2. Найти точные координаты и place_id в Google Maps, цену и часы в свежих источниках. Не выдумывать цифры: если цена не найдена — «уточняйте на месте» и `level: null`.
3. Фото: JPEG до 1600 px в `app/photos/<id>.jpg` и квадрат 400×400 в `<id>_t.jpg` (progressive, q≈80). Подпись автора — в `imgBy` («Иллюстрация, создана ИИ», «Автор / Wikimedia Commons, CC BY-SA 4.0», «из подборки»). Сверять, что на фото именно это место.
4. `npm run check`, `node tools/crypt.mjs encrypt`, затем поднять `VERSION` в `app/sw.js`, чтобы телефоны получили обновление.

## Карта

- Подложка — Esri World Topographic Map (рельеф, берег, дороги, названия улиц), грузится онлайн и кэшируется service worker'ом (до 6000 тайлов). `maxNativeZoom: 17` — если на каких-то участках Бали на 17-м зуме приходят серые «Map data not yet available», снизить до 16.
- Esri бесплатно разрешает такую подложку для личного некоммерческого использования с указанием авторства. Если приложение станет публичным/коммерческим — завести бесплатный ключ ArcGIS Location Platform или перейти на MapTiler/Stadia, сохранив светлый стиль.
- Метки — цветные «капли» с иконкой категории, кластеризация до 14-го зума. Дом — тёмная метка с домиком.

## Маршруты (байк)

`data/roads.json` = `{"gz": "<base64 от gzip(JSON)>"}`, JSON: `{N, E, G}`
- `N` — плоский массив узлов `[lat*1e5, lng*1e5, …]` (≈184 тыс. узлов);
- `E` — рёбра по 4 числа: `[a, b, cls*4 + oneway, длина_в_метрах]`; `cls`: 0 motorway, 1 trunk, 2 primary, 3 secondary, 4 tertiary, 5 unclassified, 6 residential/living_street; `oneway`: 1 только a→b, 2 только b→a;
- `G[e]` — промежуточные точки ребра как накопительные дельты от узла `a` (в тех же единицах 1e-5°), упрощено Дугласом–Пекером 6 м.

В браузере граф распаковывается через `DecompressionStream`, строится CSR-список смежности, маршрут — A* (эвристика по прямой при 55 км/ч). Скорости байка по классам: 55/45/40/35/30/25/20 км/ч + штраф 2,5 с за перекрёсток; концы маршрута «примагничиваются» к ближайшему узлу главной компоненты сети. Если нужно обновить дороги — заново выгрузить из Overpass API highway=motorway…living_street (+ `_link`), собрать тот же формат.

## Интерфейс (не ломать)

- Нижнее меню: **Карта · Места · Поездки · Моё · Ещё** (`switchTab`). Разделы кроме карты — `.page` поверх карты; кнопка «Назад» телефона закрывает разделы/карточки/маршруты через `history.pushState` + `popstate`.
- **Места**: подборки по меткам `tags[]` (закат, без толп, фрукты, дождь, купание, треккинг, романтика, с детьми, рассвет, бюджет, работа), категории, районы; сортировка подборок `byLook` — сначала места с красивыми фото (`pq`: 2 хорошее, 1 норм, 0 слабое фото).
- **Поездки**: несколько мест подряд, «Выгодный порядок» (ближайший сосед + 2-opt), маршрут по всем точкам (`computeTrip`), навигатор по остановкам, ссылка `#trip=`. Хранятся в localStorage.
- **Моё**: избранное, заметки (`bali-notes`), «был(а)» с датой. **Ещё**: свой дом для друзей (`bali-home`), схема/спутник, голос, офлайн-карта маршрута (`bali-offline` cache), советы, выход.
- «Открыто сейчас» — `parseHours/openInfo` разбирают текст `hours` по времени Бали (Asia/Makassar); непонятные строки → статус не показывается.

- Телефон (≤760 px): нижняя панель с тремя положениями peek/half/full, тянется пальцем (`touchstart/touchmove` с `preventDefault`), карта сдвигает выбранную точку в видимую часть (`flyCenter`, `padFor`). На время маршрута остальные метки скрываются.
- Компьютер: левая панель 400 px, плавающий поиск и чипсы категорий сверху.
- Шрифт Plus Jakarta Sans, токены цветов в `:root`. Тема только светлая — тёмная тема неудобна на улице.
- Поля ввода на телефоне 16 px (иначе iOS зумит страницу).
- «Где я» использует `navigator.geolocation` — работает только по HTTPS (или localhost).
- Избранное и «был(а)» хранятся в localStorage этого устройства.

## Как проверять изменения

1. `npm run check` без ошибок.
2. `npm start`, открыть в Chrome DevTools в режиме iPhone (390×844) и на ширине 1280:
   - открыть место из списка и с карты;
   - свайпнуть панель вверх/вниз;
   - построить маршрут «Дом → Analog Uluwatu» (≈43 км, ≈1 ч 25 мин) и «Дом → Nungnung Waterfall» (≈45 км);
   - маршрут на Нуса-Пениду должен показать подсказку про фастбот.
3. Консоль без ошибок. В консоли доступен `balimap` (объект карты Leaflet).

## Публикация

Это статический сайт из папки `app/`. Самое простое:
- **Netlify Drop**: перетащить папку `app` на https://app.netlify.com/drop — сразу HTTPS-ссылка.
- **Vercel**: `npx vercel deploy app --prod`.
- **GitHub Pages**: репозиторий, Pages из папки `app` (или workflow, публикующий `app/`).

После публикации на телефоне: Safari → «Поделиться» → «На экран Домой» (iPhone) или Chrome → «Установить приложение» (Android).

Нативное приложение (по желанию): обернуть `app/` в Capacitor (`npm i @capacitor/core @capacitor/cli @capacitor/ios @capacitor/android`, `webDir: "app"`), геолокацию — через `@capacitor/geolocation`. Для iOS нужен Mac с Xcode, для публикации в App Store — аккаунт Apple Developer.

## Что осталось / идеи
- Подборка «Новые места» слишком большая (~100 мест) — сузить.
- «Свой дом» можно поставить в море — добавить проверку.
- ~35 старых фото меньше 800 px — заменить на лучшие.
