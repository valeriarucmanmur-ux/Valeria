# Бали без толп — приложения для Android и iPhone

Приложение-карта из папки `app/` упаковано в нативные приложения с помощью Capacitor:
- `android/` — проект Android (Android Studio);
- `ios/` — проект iOS (Xcode);
- `capacitor.config.json` — общие настройки (id `com.valeria.balimap`, название «Бали без толп»).

Внутри всё то же: 195 мест, фото, маршруты на байке, «Где я» (через нативный GPS телефона), избранное и «был(а)».
Фото, данные и дороги лежат внутри приложения; подложка карты грузится из интернета.

## Ссылка для iPhone и Android (сайт-приложение)

https://valeriarucmanmur-ux.github.io/Valeria/

Откройте в Safari (iPhone) или Chrome (Android) → «Поделиться» → «На экран Домой» / «Установить приложение».

## Пароль

Всё приложение закрыто паролем: без него не видно ни мест, ни дома, ни цен. Данные хранятся только в зашифрованном виде
(`app/data/places.enc.json`), поэтому даже в открытом репозитории их не прочитать.
Пароль вводится один раз на устройстве (галочка «Запомнить»). Выйти: окно «Важно» → «Выйти и заблокировать».

## Навигация в приложении

- «Где я» — точка следует за вами и показывает направление движения.
- Маршрут → «Пошагово»: список поворотов, нажатие показывает поворот на карте.
- «Поехали» — навигатор: следующий поворот и расстояние до него, голосовые подсказки по-русски,
  время прибытия, автоматический пересчёт, если свернули не туда, экран не гаснет.
- Кнопка со слоями — спутник / схема.
- Google Maps по-прежнему открывается из карточки места, маршрута и навигатора.

## Где взять готовые файлы

Каждый push в репозиторий автоматически собирает приложения на GitHub:
**Actions → «Сборка приложений (Android + iOS)» → последний запуск → Artifacts**:
- `bali-android-apk` — файл `bali-bez-tolp.apk` для Android;
- `bali-ios-unsigned-ipa` — файл `bali-bez-tolp-unsigned.ipa` для iPhone (без подписи).

Скачанный артефакт — это zip, внутри него лежит файл приложения.

## Android

1. Скачайте `bali-android-apk` на телефон (или на компьютер и перешлите APK на телефон).
2. Распакуйте zip и откройте `bali-bez-tolp.apk`.
3. Android спросит разрешение «Устанавливать из этого источника» — разрешите для браузера/файлового менеджера.
4. Установите, откройте, при нажатии «Где я» разрешите доступ к геолокации.

## iPhone

Apple не разрешает ставить приложения просто файлом — IPA нужно подписать. Варианты:

**A. Бесплатно, через компьютер (Sideloadly или AltStore)**
1. Установите Sideloadly (sideloadly.io) на Windows или Mac.
2. Подключите iPhone кабелем, перетащите `bali-bez-tolp-unsigned.ipa` в Sideloadly, введите свой Apple ID, нажмите Start.
3. На iPhone: Настройки → Основные → VPN и управление устройством → доверять своему Apple ID.
4. На iOS 16+ включите «Режим разработчика» (Настройки → Конфиденциальность и безопасность).
Минус: с бесплатным Apple ID подпись живёт 7 дней, потом повторить шаг 2.

**B. Через Mac с Xcode**
```bash
npm ci
npm run photos
npx cap sync ios
npx cap open ios
```
В Xcode: App → Signing & Capabilities → Team = свой Apple ID, выбрать iPhone, нажать ▶.

**C. Надолго и без кабеля — TestFlight / App Store**
Нужен Apple Developer Program (99 $/год). Тогда можно настроить подпись в GitHub Actions и выкладывать в TestFlight автоматически.

Требования: iOS 16.4+, Android 7+ (с обновлённым Android System WebView).

## Как обновлять приложение

1. Меняете `app/` (места, тексты, `index.html`) как раньше — см. `CLAUDE.md`.
2. `git push` — GitHub сам соберёт новые APK и IPA.
3. Локально (если есть Android Studio / Xcode): `npx cap sync`, затем `npx cap open android` или `npx cap open ios`.

Иконки и заставки генерируются из `assets/`: `npx capacitor-assets generate --ios --android`.

## Отличия от PWA-версии

- «Где я» работает через нативную геолокацию (вопрос о разрешении задаёт система).
- Service worker в приложении выключен: фото и данные и так внутри приложения. Тайлы карты кэширует сам WebView.
- Ссылки на Google Maps и Instagram открываются в соответствующих приложениях / браузере.
- Ориентация — только портретная.
